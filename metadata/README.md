# metadata

Supplementary tables for the paper.

- `supplementary_table_1.txt` — per-sample statistics: reference assignment, coverage, callable sites, genotype counts, sex assignment, heterozygosity.
- `supplementary_table_2.txt` — sequencing read accessions: BioSample, BioProject, SRA/ENA run IDs, FASTQ URLs, sizes, and md5 checksums for each R1/R2 file.
- `supplementary_table_3.txt` — reference genomes used per species, with GenBank IDs and download URLs.
