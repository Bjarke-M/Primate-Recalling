# data

Shared input tables and trees used by the figure notebooks.

- `SupTable_Sample_Stats_wGT_QC_MQ.tsv` — per-sample statistics including coverage, genotype counts, heterozygosity, QC flags, and mapping quality.
- `SupTable_Sample_Stats_wGT_QC_ColumnDescription.tsv` — column descriptions for the table above.
- `cactus_aligmnent.tsv` — per-species cactus alignment coverage, identity, and divergence vs. *H. sapiens*.
- `contigs_in_ref_genomes.tsv` — per-reference contig annotation and length classes.
- `phylogeny_49_species.nwk` — species tree (Newick) for 49 primates.
- `ref49_sex.txt` — per-reference sex assignment for the 49-species set.
- `alnRegionHet.zip` — per-species BED outputs and callable-region tables used by Figure 5.
