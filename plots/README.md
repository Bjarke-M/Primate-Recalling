# plots

Code and input data for the figures in the paper.

- `figure1/` — coverage overview (Figure 1).
- `figure2/` — cactus whole-genome alignment summary (Figure 2).
- `figure3/` — species tree and per-species statistics (Figure 3).
- `figure4_and_S4/` — PCA setup and plotting (Figure 4 and Supplementary S4).
- `figure5/` — callable regions from chain files (Figure 5).
- `figureS1/` — genetic sexing (Supplementary S1).
- `figureS2/` — mapping quality (Supplementary S2).
- `figureS3/` — reference genome properties (Supplementary S3).
- `data/` — shared input tables and trees used by the figure notebooks.

Each figure folder is self-contained: open the notebook or R script and run it against the files in `data/`.
