# annotate_sex_chr

Identify sex-chromosome-derived contigs in each reference genome and assign genetic sex (XX or XY) to every sample.

## Files

- `sex_contigs_genome_annotation.tsv` — per-contig sex-chromosome annotation across references.
- `reference_T2T.txt` — references at telomere-to-telomere quality.
- `reference_uneven_sexes.txt` — references with unbalanced sex representation.
- `reference_poorN50.txt` — references flagged for low contig N50.
- `samples_removed.txt` — samples excluded from downstream analyses.
